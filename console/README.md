# 本地控制台

双击项目根目录的 `start-console.cmd` 打开启动器与工作台。界面在 Microsoft Edge 的独立应用窗口中运行，没有浏览器地址栏。点击顶部“启动服务”，就绪后显示存档与工作台；游戏仍由工作台中的“启动游戏”按钮启动。

游戏服务默认连接 `http://127.0.0.1:18083`。启动器使用独立的本机端口，服务关闭时仍可使用；顶部提供启动、停止、重启，底部可展开最近服务日志。关闭窗口会保留后台服务，重新打开沿用同一个启动器。

从 PowerShell 启动的服务显示“外部服务”，可以直接连接。若要改由控制台管理，请在原 PowerShell 窗口按 Ctrl+C 停止一次，再点“启动服务”。之后无需打开服务 PowerShell 窗口。停止或重启会先等待正在处理的请求结束，游戏连接会中断；操作前请先完成当前游戏动作。

启动器从 `data-pc-1.15.0/admin-token.txt` 读取管理凭据，申请一次性票据后在原服务页面打开工作台。启动器本身也使用独立的一次性票据与本机会话。网页认证后立即清除地址中的票据；管理凭据不会进入网页或窗口配置。

服务地址或目录不同，可运行 `start-console.ps1 -Port 18083 -DataDirectory '你的数据目录'`。连接参数会保存在当前用户的 `DotAbyssConsole/settings.json` 中，下次启动自动沿用。

1. 在顶部选择存档，或点击“新建存档”。新档从教程开始，可分别填写存档名称与游戏昵称。
2. 在左侧选择功能，再从“可用操作”中选择需要修改的内容。
3. 填写参数；可点“选择…”按名称或 ID 查找，并勾选多条记录。
4. 点击“预览修改”，核对变动数量、提示和生效方式。
5. 点击“应用修改”，留意底部客户端同步状态。

需要进入游戏时，点击“启动游戏”。启动前会核对资源和插件绑定，再写入所选档案的内部标识。游戏已经运行时不会启动第二份，也不会在运行中偷换档案。顶部会分别显示当前编辑的档案与游戏使用的档案。

“繁体中文”栏提供一键安装或更新翻译，并可展开进度与日志。需要先退出游戏；安装过程使用独立后台任务，不要求游戏服务在线。完成后下次启动游戏生效，具体来源与依赖见 [翻译集成说明](../pc-translation/README.md)。

打开窗口时优先选中正在运行的游戏档案，其次恢复上次选择。重命名只改变启动器中的中文显示名称，不修改内部登录标识或游戏昵称；修改游戏昵称仍在“玩家资料”操作中进行。

“存档数据”只读，供核对字段；“内容目录”查看当前主表记录。“本地规则”和“主数据”有独立的预览流程，未开放编辑的字段为只读。修改表单、切换存档或发现存档已变化时，旧预览会失效。

表名与字段使用中文说明，原始键名保留为辅助信息。角色、装备实例、技能、卡池、商品、剧情和奖励会关联当前主数据名称，并同时保留 ID；已有翻译缓存时优先显示游戏译名，搜索兼容译名、原文与 ID。选择或输入 ID 后会显示名称摘要，嵌套奖励和修改预览也可查看名称对照。

名称仅用于显示，编辑提交和存档导出仍使用原始数据。没有可靠名称或关联不明确的编号保留原值。窄列表可以横向滚动，长名称换行，点击数据行可查看完整字段。

“存档备份”可以手动备份、导出到 JSON、导入并预览，以及预览恢复到某次操作之前。恢复也需再次点击应用，打开文件不会直接覆盖存档。

快捷键：F5 刷新当前页面，Ctrl+F 聚焦当前搜索框。会话失效后重新运行启动器即可。

`start-console.ps1 -Demo` 打开明确标注的隔离界面演示，不连接真实服务。`-NoConnect` 同样只进入演示。仅在需要备用界面时使用 `-Classic`；备用窗口支持原有 Tk 管理流程。

定向验证：`node --test console/tests/test_web_fields.cjs` 检查网页字段处理和隔离演示；`python -m pytest console/tests/test_web_launcher.py` 检查启动器凭据交接。备用界面的检查为 `python -m pytest console/tests/test_console.py`。这些测试不访问真实服务或游戏。
