# 控制台界面

以 Edge 应用窗口承载本机网页，主界面不出现浏览器地址栏；Python 只负责读取本机管理凭据、申请一次性窗口票据和启动窗口。网页认证后立即删除地址中的票据。

画面采用深梅紫导航、浅灰紫工作台、白色编辑面板和绿色同步状态。主色集中定义为 `#241D35`、`#F5F4F8`、`#FFFFFF`、`#2D253A`、`#7652CC`、`#258572`。字体优先使用 Microsoft YaHei UI 与 Segoe UI Variable，数字使用等宽数字特性；间距、尺寸、边框、圆角全部引用主题变量。

布局包含固定功能侧栏、顶部存档与连接状态、中央可搜索操作列表，以及右侧宽敞的表单与变更预览。不使用营销标题、装饰数据卡或大面积渐变。选中操作使用紫色窄线，保存动作固定在表单底部。

```
连接地址       当前存档              客户端同步状态
功能分类 | 搜索、操作和数据目录 | 字段编辑 / 修改预览
         |                    | 预览修改、应用修改
操作结果与待生效提示
```

状态色只用于离线、等待、成功或失败；所有状态都有文字。错误就地显示并保留输入，服务器返回过期预览后要求重新预览，不会自动重试写入。切换存档或修改表单会作废旧预览，避免误提交到另一存档。

普通操作使用可理解的中文名称和类型化输入；数据明细保留原字段供核对。独立演示模式只使用合成数据，不连接真实存档或发送写请求，用于布局和交互检查。
