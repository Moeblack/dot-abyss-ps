# 通行证任务与领奖

通行证任务领取后发放通行证点数；达到等级后，普通奖励和已购买的高级奖励分别领取。领取记录持久保存，重复请求不会再次发奖。满级后的循环奖励按未领取的点数区间结算。

累计任务只统计当前通行证开始至结束之间的行为。周任务按通行证开始日期的星期，在日本时间 05:00（北京时间 04:00）刷新；第一周从实际开期时刻开始，最后一周在通行证结束时截止。例如 202611 通行证在周六开期，因此每周六刷新，而非周一。

统计保存在 `features.missions.data.pass_statistics`，普通任务原有的日统计和总统计保持独立。任务自带的有效期限会进一步缩小统计窗口。深渊成功结算归还、撤退或败退时登记一次挑战结束；重复结算、已结算记录的读取和单纯放弃未结算流程不会增加次数。

旧存档只从完整落在新统计窗口内的日记录恢复计数。开期当天、刷新当天等不足整日的旧记录无法可靠拆分，不推测其时间归属；这些原始记录仍保留。历史深渊结束次数未记录时也不补猜。已有通行证等级、积分、奖励和购买权益不变。

旧的 ISO 周领奖记录在对应历史窗口中保守映射为已领取，避免升级或回退系统时间后重复发奖；后续新周使用独立记录。只有当有效通行证存在可领取任务、普通／高级等级奖励或循环奖励时，主页通行证红点才亮。
